EPIC 4: CORE APIs & TICKET ECONOMY (Weeks 4-5)
  Status: 10 tasks, 10 days
  Owner: Backend Lead
  
  4.1 Create Authentication API Endpoints (1 day)
      - POST /api/auth/signup, /api/auth/login, /api/auth/logout
      - POST /api/auth/refresh (token rotation)
      - POST /api/auth/password-reset
      - Rate limiting: 5 attempts per 15 min
  
  4.2 Create User Profile API Endpoints (1 day)
      - GET /api/profile (user profile)
      - PUT /api/profile (update profile)
      - POST/GET/PUT/DELETE /api/kids (child management)
      - POST /api/profile/consent/[kid-id]/revoke
  
  4.3 Create Toy Listing API Endpoints (1 day)
      - POST /api/toys (create listing, -1 ticket cost)
      - GET /api/toys (search with filters, pagination)
      - GET /api/toys/[id] (detail page)
      - PUT /api/toys/[id] (update)
      - DELETE /api/toys/[id] (soft delete)
      - GET /api/toys/my-listings (user inventory)
      - Photo upload to Supabase Storage
  
  4.4 Implement Ticket Economy Endpoints (1 day)
      - GET /api/wallet (balance, available, frozen, earned)
      - GET /api/wallet/history (transaction log)
      - POST /api/wallet/redeem-fragments (4 fragments = 1 ticket)
      - GET /api/wallet/starter-allocation
  
  4.5 Create Exchange Request/Accept Endpoints (1 day)
      - POST /api/exchanges (request toy, -1 ticket frozen)
      - POST /api/exchanges/[id]/accept (lister accepts)
      - POST /api/exchanges/[id]/decline (lister declines, +1 ticket refund)
      - GET /api/exchanges (list user's exchanges)
      - GET /api/exchanges/[id] (detail)
      - Timeout: 48h auto-cancel if no response
  
  4.6 Implement Delivery Confirmation Endpoint (1 day)
      - POST /api/exchanges/[id]/confirm-delivery
      - Condition selection: like_listed, minor_wear, damage, missing_parts
      - Photo upload (optional, up to 2)
      - Dispute triggering: condition='damage' → status='disputed'
      - Auto-completion after 7 days
  
  4.7 Create Wishlist API Endpoints (1 day)
      - GET /api/wishlists/[kid-id]
      - POST /api/wishlists/[kid-id]/items (add toy or custom wish)
      - PUT /api/wishlists/[kid-id]/items/[item-id] (reorder, update)
      - DELETE /api/wishlists/[kid-id]/items/[item-id]
      - GET /api/wishlists/[kid-id]/suggestions
      - Max 50 items per wishlist
  
  4.8 Create Messaging Endpoints (Exchange-scoped) (1 day)
      - POST /api/exchanges/[id]/messages (send message, max 500 chars)
      - GET /api/exchanges/[id]/messages (thread history)
      - DELETE /api/messages/[id] (soft delete)
      - Auto-moderation: Flag phone #, addresses, payment terms
      - Message retention: Delete 30 days after exchange completion
  
  4.9 Implement API Rate Limiting & CORS (1 day)
      - Rate limiting: 1,000 reqs/hour per IP, stricter per-endpoint
      - CORS: Allowed origins (localhost, production domain, Vercel previews)
      - Security headers (X-Frame-Options, etc.)
      - Input validation, content-type checks
      - Error response format standardization
  
  4.10 Create API Documentation (OpenAPI/Swagger) (1 day)
       - OpenAPI 3.0 specification created
       - Swagger UI at /api/docs
       - 35+ endpoints documented with examples
       - Error handling guide
       - Rate limiting documented
